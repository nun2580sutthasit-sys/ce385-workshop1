## Workshop 2 · ข้อที่ 2 — ทะเบียนนักศึกษา
การจัดการข้อมูลแบบ Immutability: จัดเก็บข้อมูลนักศึกษาในรูปแบบ Array of Objects และใช้ Spread Operator ([...students, newStudent]) ในการเพิ่มข้อมูลใหม่เพื่อไม่ให้กระทบ Array ต้นฉบับ

ฟังก์ชันค้นหาข้อมูล: ใช้ Built-in Methods ได้แก่ find() สำหรับค้นหารายบุคคล, filter() สำหรับคัดกรองตามสาขา และ some() สำหรับตรวจเงื่อนไขคะแนนตก

การเข้าถึงข้อมูลอย่างปลอดภัย: ใช้ Optional Chaining (?.) ควบคู่กับ Nullish Coalescing (??) ในฟังก์ชัน getEmail เพื่อป้องกัน Runtime Error กรณีไม่พบ Object หรือไม่มี Property contact พร้อมคืนค่าเริ่มต้นหากข้อมูลเป็น null หรือ undefined

## Workshop 2 · ข้อที่ 3 — สรุปผลการเรียน
Higher-Order Functions: ใช้เฉพาะ map, filter, และ reduce ในการจัดการข้อมูลทั้งหมดโดยไม่ใช้คำสั่งลูป for หรือ while

การคำนวณและแปลงรูปข้อมูลด้วย reduce: กำหนด Initial Value เสมอ เช่น เริ่มต้นด้วย 0 สำหรับคะแนนรวม, {} สำหรับจัดหมวดหมู่นับเกรด และ null สำหรับการหาผู้ที่ได้คะแนนสูงสุด เพื่อให้ฟังก์ชันทำงานได้ปลอดภัย

การต่อท่อข้อมูล (Chaining Pipeline): ต่อฟังก์ชัน filter -> map -> reduce ในบรรทัดเดียวเพื่อคัดกรองสาขา CE ที่ผ่าน ดึงเฉพาะคะแนน และคำนวณค่าเฉลี่ยออกมาได้ทันที

การจัดการกรณีขอบ (Edge Case): ตรวจสอบความยาวของ Array ล่วงหน้าใน getAverageScore หากส่ง Array ว่าง ([]) เข้ามา จะคืนค่า 0 ทันทีเพื่อป้องกันปัญหาการหารด้วยศูนย์ที่ทำให้ได้ค่า NaN
